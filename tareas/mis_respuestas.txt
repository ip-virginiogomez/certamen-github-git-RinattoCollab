PREGUNTA 1 (5 pts)
¿Cuál es la diferencia entre "git add" y "git commit"?

Tu respuesta:
[Git add es para preparar los archivos o por así decirlos que todos esten dentro del ascensor "una area de preparacion"
y el Git commit es para que todo lo que preparaste se suba y quede guardado permanentemente.]

----------------------------------------------------------------
PREGUNTA 2 (5 pts)
¿Qué hace el comando "git pull"? ¿Cuándo debes usarlo?

Tu respuesta:
[El comando Git Pull descarga los ultimos cambios que están en el repositorio remoto (por ejemplo en Github) y los fusiona automaticamente con el repositorio local.
¿Cuando se debe de usar? Antes de empezar el trabajo para asegurarte de que estás escribiendo codigo sobre la version mas actualizada del proyecto.]

----------------------------------------------------------------
PREGUNTA 3 (5 pts)
¿Qué diferencia hay entre un repositorio local y uno remoto?

Tu respuesta:
[El repositorio local es una copia del proyecto que vive dentro de tu computador, aqui puedes editar los archivos para hacer pruebas y guardar tu progreso diario con git commit. Es un entorno de trabajo privado y no necesitas internet.
El repositorio remoto es una version del proyecto alojada en un servidor externo o en la nube (como github), Funciona como el punto de encuentro o respaldo central de tu codigo. Necesitas internet para sincronizarte con él, ya sea enviando tus cambios o descargando los otros (git pull y git push) ]

----------------------------------------------------------------
PREGUNTA 4 (5 pts)
Escribe la secuencia completa de comandos para subir un nuevo
archivo llamado "datos.csv" a GitHub (desde git add hasta push):

Tu respuesta:
[primero hay que preparar el archivo y subirlo al area de trabajo con git add datos.csv
luegon hay que hacer git commit -m con un mensaje "Agrego archivo de de datos" para que tenga un mensaje descriptivo
y por ultimo hay que enviar el commit desde tu repositorio local al repositorio remoto con  git push origin "el nombre de la rama"]
